F-Chat

Файлы статического веб-приложения. Для публикации загрузите содержимое этой папки в корень репозитория GitHub (index.html, manifest.webmanifest, sw.js, icon.svg). Не загружайте ZIP как единственный файл.

Backend: Supabase project xootijonpduwyrjxgjiw. В index.html используется только publishable key, не service_role.

Важно перед публичным запуском:
1. В Supabase Authentication настройте Site URL и Redirect URLs для домена опубликованного сайта.
2. Убедитесь, что включено подтверждение почты или настройте его по своему выбору.
3. Проверьте таблицы и политики RLS. Это приложение рассчитано на таблицы profiles, friend_requests, conversations, messages с полями, которые уже созданы в проекте.
4. Для PWA нужен HTTPS и публикация всех файлов в корне сайта.

Текущая версия: первая рабочая сборка интерфейса и базовых функций. «Избранное» пока локальная заглушка заметок; чат с друзьями использует Supabase.
